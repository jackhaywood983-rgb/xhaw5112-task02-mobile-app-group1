# Design reference notes

- Dark navy/near-black base with elevated panels.
- Cyan/teal primary actions; purple/magenta accent lighting.
- Premium illuminated gaming-arena photography.
- Rounded cards, compact branded header, clear CTA hierarchy.
- Desktop uses top navigation; mobile uses a persistent bottom-tab pattern.
- Prioritize WCAG 2.1 basics, visible focus, readable contrast, and 44–48 px tap targets.
- Do not replace the supplied visual language with a generic light theme.
